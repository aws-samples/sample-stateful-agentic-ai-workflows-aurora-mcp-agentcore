# Deployment and UI follow-up - 20 September 2026

This report follows [the earlier E2E review](READINESS_2026-09-20.md). Earlier results remain historical. The [deployment runbook](DEPLOYMENT_FOLLOWUP.md) contains the current publisher, provisioning, migration, Finch and rehearsal procedures.

**Encryption assessment correction:** the original database and final rollback snapshot have `StorageEncryptionType=sse-rds`, so both were already encrypted with an AWS-owned key. The earlier assessment incorrectly treated `StorageEncrypted=false` as unencrypted storage. The migration was unnecessary for encryption at rest; it changes the key mode to `sse-kms` using an AWS-managed KMS key. After this correction was disclosed, the operator explicitly chose to keep the replacement active and preserve the original for rollback. The preflight now reads the authoritative encryption type, with regression coverage for the misleading legacy flag.
